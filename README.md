# ComfyBridge

面向 Windows x86_64 的本地 OpenAI 兼容 TTS 中间层，将 `(model, voice)` 映射到 ComfyUI 工作流。支持 WAV／MP3、独立后台、控制台 Monitor 和配置向导。

**当前为 0.2.0 双语菜单版，版本验证见 [0.2.0 验收记录](<docs/UI_020_VALIDATION.md>)，基础服务验证见 [MVP 验收记录](<docs/VALIDATION.md>)。** 不包含模型权重、参考音频或正式 API Key，不修改 ComfyUI 安装和画布。

## 快速开始：目录包

1. 将整个发行目录解压到当前用户可写的位置。保留 EXE、`_internal` 和 `bin`，不要只复制 EXE。
2. 双击 EXE，首次选择 `[1] 简体中文` 或 `[2] English`。以后不再询问，主菜单 `[A] 语言 / Language` 可随时修改。
3. 跟随首次引导手动设置业务 API Key、监听地址、端口和 ComfyUI URL。同机访问默认 `127.0.0.1:18388`；其他机器上的 AstrBot 需要使用实际局域网 IP 或监听 `0.0.0.0`。`0.0.0.0` 不能作为客户端目标地址。程序不自动修改防火墙。
4. 添加模型 `index-tts-2.5`，缓存策略初始选 `inherit`（跟随工作流）。也可暂时跳过模型／音色配置，但没有有效音色前不能合成。
5. 导入你的工作流，或使用 [Example API 示例](<examples/workflows/index-tts-2.5_example.json>)；登记音色 `example`，文本选节点 `2` 的 `text`，音频出口选 `4`，缓存绑定选节点 `3` 的 `keep_models_cached`。
6. 查看脱敏摘要并明确保存。程序自动启动／连接后台，然后进入主菜单；启动失败也保留菜单供你修复，不反复自动重试。
7. 选择 `[1]` 查看实时状态，确认就绪后在 AstrBot 填写下方连接信息。日常不需要手敲命令行。

示例引用的参考音频必须已存在于 **ComfyUI 机器**，并能被其 LoadAudio 节点访问。导入 JSON 不上传参考音频，不复制模型文件。

### AstrBot 配置

| 项目 | 值 |
|---|---|
| 提供商类型 | OpenAI TTS API／OpenAI Compatible TTS |
| API Base | `http://中间层实际IP:18388/v1` |
| API Key | 你在向导中设置的同一业务 Key |
| 模型 | `index-tts-2.5` |
| 音色 | `example` |
| 超时 | 建议大于中间层默认 300 秒，例如 330 秒；需确认所在版本确实支持该设置 |

不要把 API Base 填成 ComfyUI 的 8188 端口。当前尚未操作用户的 AstrBot 安装；上游调用支持不等于所有安装版本均已验收。

## 主菜单：输入编号后回车

```text
              ComfyBridge — 功能选择
------------------------------------------------
 后台：已确认连接     ComfyUI：已连接
 配置：已生效         语言：简体中文

 [1] 查看状态与实时日志
 [2] 启动后台
 [3] 停止后台
 [4] 重启并应用配置

 [5] 修改服务连接与 API Key
 [6] 管理模型与缓存
 [7] 管理音色与工作流
 [8] 高级设置
 [9] 登录自启动设置

 [A] 语言 / Language
 [0] 退出窗口（不停止后台）
```

- 选项 6／7 分别提供查看、新增、修改、删除；所有菜单纵向排列。
- 选项 8 包含限制／日志设置、脱敏配置摘要、强制停止和不确定任务核对。
- 编辑页 `S` 校验保存，`0`／`Q` 返回。有未保存修改时，可选择保存、放弃或继续编辑。
- 保存业务配置不会热加载：可以明确选择“现在重启应用”，也可以稍后从主菜单重启。确认提示空回车默认取消。
- 首页为空回车刷新状态；选项 1 的 Monitor 实时刷新，`0`／`Q` 返回首页。
- 主菜单 `0`／`Q`、终端退出或窗口关闭不会停止后台。后台崩溃不会自动复活；手动停止后，菜单刷新也不会又自动启动。
- 语言按数据目录单独保存，切换立即作用于当前窗口，不重启服务、不改变业务配置。
- 未经确认不会安装自启动快捷方式。选项 9 启用后，登录时启动后台并打开主菜单；移动目录后需重新登记。

## 从 0.1.0 升级

1. 在旧版 Monitor 中选择停止，确认旧后台退出；不要只关闭窗口。
2. 将新版解压到独立目录，不覆盖正在运行的旧 EXE。
3. 停止后把原数据目录完整复制到新版程序旁，或继续明确指定原数据目录。保留工作流、账本和快照，不删除未知任务记录。
4. 双击新版，只需补选语言；有效的原配置不会要求重新输入。已有语言偏好会继续使用。
5. 若原来启用过登录自启动，在新版菜单 9 更新登记；变更数据目录时还需从旧目录对应的管理入口禁用旧快捷方式。

新旧版本不会互相冒充管理实例。看见身份无法确认提示时，先用旧版窗口处理旧后台，不按 PID 猜测结束进程。

### 可选命令行（供自动化，日常无需使用）

```powershell
.\ComfyBridge.exe
.\ComfyBridge.exe configure
.\ComfyBridge.exe start
.\ComfyBridge.exe monitor
.\ComfyBridge.exe status
.\ComfyBridge.exe restart
.\ComfyBridge.exe stop
.\ComfyBridge.exe --data-dir 'D:\MyBridgeData' monitor
```

- 无子命令：首次选语言／配置，自动启动或连接后台，然后打开主菜单。
- `start`：启动后台后退出，不一直占用终端。
- `monitor`：只打开管理窗口；Q、Ctrl+C 或关闭该窗口不停止后台。
- `restart`：启动独立控制进程，停止新请求、排空已有任务后重启；关闭 Monitor 不终止控制流程。
- `stop`：需明确确认。`stop --force` 只强制停止中间层，远端任务可能继续，账本不会删除。
- 配置保存后不热加载，Monitor 区分当前运行配置与待生效配置。
- 后台崩溃不会自动重启；Monitor 提示故障，可手动启动。

登录自启动默认关闭，仅在明确执行下列操作时修改当前用户 Startup 快捷方式：

```powershell
.\ComfyBridge.exe startup enable
.\ComfyBridge.exe startup disable
```

也可直接在菜单 9 中管理。启用后登录时同时启动后台并打开主菜单。移动目录后需重新登记；未登录或注销后持续运行不在本版保证范围内。脚本与内部后台命令不弹语言选择，未设置偏好时使用 English；`status` 保持机器可读 JSON。重定向输入输出使用 UTF-8，管道菜单按每行一个选项处理。

## 请求格式

```json
{
  "model": "index-tts-2.5",
  "voice": "example",
  "input": "你好，这是语音测试。",
  "response_format": "wav"
}
```

- `POST /v1/audio/speech`：返回音频二进制，格式为 WAV 或 MP3，省略格式默认 MP3。
- `GET /v1/models`：返回去重模型列表，离线时仍可使用。
- 两者均要求 `Authorization: Bearer <Key>`。API Key 不提供传输加密，HTTP 仅用于可信局域网。
- `model`／`voice` 精确区分大小写，音色不会通过模型列表自动分发。
- 默认文本上限 4096 个 Unicode 码点，可配置；不自动分段、截断或改写。
- `speed` 只接受省略或数值 `1.0`；这表示不在工作流预设基础上额外变速。
- `instructions` 只接受省略或空白字符串；未知字段、非中性参数、重复 JSON 键或显式 `null` 返回 400。

错误体采用 OpenAI 风格：400 参数、401 鉴权、413 请求体、429 队列满、502 后端／音频失败、503 未就绪／排空／状态不明、504 超时。SDK 自动重试可能重复生成；建议调用端关闭自动重试，不认为同样文本代表同一次意图。

## 缓存策略

模型级策略为 `inherit`（默认跟随模板）、`keep`（覆盖 true）、`release`（覆盖 false）。显式覆盖需要每个预设有有效缓存控制绑定。当前支持 IndexTTS 2.5 的 Cache Control 节点，不开放任意请求字段覆盖任意节点。

修改策略重启后用于后续请求，不立即卸载 ComfyUI 已缓存的模型；不同模型 ID 也不代表彼此隔离的显存缓存。

## 模板与数据

默认数据位于程序旁的 `data`，可通过 `--data-dir` 指定其他位置；不可写即报错，不偷偷换目录。配置是 UTF-8 JSON，示意见 [示例配置](<examples/config.example.json>)；其中 Key 特意留空，**不能直接作为有效生产配置启动**。

- 模板导入复制到管理目录，源文件修改不自动同步；替换需重新确认绑定，重启生效。
- API JSON 为标准输入；只对已知的四节点 Example 风格平铺 WebUI 图提供转换，不支持任意子图、bypass 或虚拟节点。
- 前端 `control_after_generate=randomize` 不属于 API 输入。首版保留模板固定种子，导入时会提示。
- 向导新增、修改、删除预设不执行生成；模型和参考音频仍由 ComfyUI 管理。
- 备份数据目录会包含你手动配置的 Key，应按敏感文件保管。运行状态和快照仅授权当前用户及 SYSTEM。
- 单实例互斥目前限定同一 Windows 登录会话；不要在多个登录会话同时使用同一个数据目录。

## 任务恢复与安全边界

默认 1 个处理槽、8 个等待名额、总时限 300 秒，均可配置。ComfyUI 暂时离线时后台保持未就绪，拒绝新 TTS 请求，连接恢复并校验通过后接收请求。

每条请求提交前记账并生成唯一 UUID；**一个 UUID 不使 ComfyUI 自动去重**。提交结果不明时暂停新提交并核对，不能通过重启中间层绕过；不重放旧请求。

取消只尝试删除本项目尚在排队的任务；已经执行的任务自然结束，不调用全局中断或清队列。历史缺失不证明任务没有执行。如果确实无法自动核对，可在自行确认远端状态后，从**菜单 8 → 核对状态不明的任务**选择准确任务并确认风险。自动化也可使用本机管理命令：

```powershell
.\ComfyBridge.exe resolve <任务ID>
```

该命令是人为确认放弃核对，不是证明远端结束，更不是重新执行。不要在不确定时随意确认。

中间层不保留历史音频；临时文件在响应结束或失败后清理，不删除 ComfyUI 端文件。日志只记录元数据及脱敏错误，默认每份 10 MiB、5 份备份。**ComfyUI 自身的历史和音频元数据可能仍保留原文**。

管理接口仅绑定本机回环地址，使用独立运行期凭证。业务 Key 不具有停止、重启或改配置的权限；不提供远程管理界面。

## 开发与构建

```powershell
uv sync --frozen --python 3.13
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m comfybridge --data-dir .\data-dev configure
pwsh -File .\scripts\build.ps1
```

源码构建需要 PowerShell 7（`pwsh`）与 uv；运行已解压目录包不需要安装 Python 或 PowerShell 7。

正常测试使用模拟 ComfyUI，不提交 GPU 任务。直接真实实验脚本需要用户明确授权；已有意图记录的实验拒绝重复执行。当前四次真实 Example 生成结果见 [实验记录](<docs/EXPERIMENTS.md>)。

构建会获取校验和固定的 FFmpeg／ffprobe，保留共享 DLL、许可和源码来源，生成独立目录及 ZIP。签名、外网部署、Windows 服务、多用户和通用工作流编辑器均不在当前范围。
