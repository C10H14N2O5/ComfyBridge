# 安装与更新 / Install and update

## 只下载一个文件

每个版本提供完整离线 Setup EXE，可保留版本化文件名或改名为 `Setup.exe`。把它放入想使用的文件夹，双击选择：

```text
1. 安装 / Install
2. 更新 / Update
0. 退出 / Exit
```

目标始终是 Setup 本身所在文件夹，不是命令行当前目录，也不是系统临时解压目录。首次安装请使用专用空文件夹，例如 `D:\ComfyBridge`。选择当前用户可写的本地固定 NTFS 磁盘；不使用系统目录、网络盘、同步盘或链接目录。

Setup 内置程序、Python 运行依赖、FFmpeg／ffprobe 和许可材料，不要求联网或预装 Python。安装之后仍有多个运行目录，这是正常的；不再需要用户手工复制它们。Setup 完成后可以删除，但不要单独移动 `ComfyBridge.exe` 或删除 `_internal`、`bin` 等程序依赖。

Setup 不自动启动业务。安装后双击 `ComfyBridge.exe`，由原来的双语向导完成配置；不会自动填入生产 Key、模型或参考音频。

## 更新步骤

1. 暂停客户端请求，在旧版主菜单停止后台。等待已接收任务完成，再退出所有窗口。**关窗口不等于停后台。**
2. 把新版 Setup 放回原程序文件夹，选择更新。
3. 核对旧／新版本和路径；默认备份程序旁的 `data`。若使用外部数据目录，选择其实际绝对路径。
4. 确认后等待备份、校验和文件替换。仍有占用时可关闭旧程序后“重新检查”；安装器不会结束任何进程。
5. 成功后自行启动新版验证语音。Setup 只验证程序文件和本地依赖，不使用你的配置启动业务、不提交 ComfyUI 生成。

配置、工作流、语言偏好、Key 和任务账本保持原位。安装器及新版程序会使用独立的零字节生命周期锁文件进行协调；它不是业务数据，不作为数据备份内容。外部数据选择**仅用于备份**，不会改变双击默认数据目录；继续使用原有 `--data-dir` 命令或快捷方式。同一路径更新无需重新登记自启动，Setup 也不会自动修改登记。

相同版本可选择修复缺失／损坏的受管理程序文件；较旧版本禁止覆盖新版本。无法可靠识别的目录拒绝更新，不把它当成空目录。

更新可能替换你手动修改过的受管理程序文件，确认前会列出变更。额外文件保留；新程序路径与无法确认归属的文件冲突时，停止并提示你处理。旧包遗留而无法证明应当删除的文件也会保留，安装器不对整个目录执行清空操作。

## 备份与清理

备份位于安装目录的 `backup/<事务ID>/`。包含更新前程序和选定数据目录，可能包含 Key 和运行期凭证，按敏感数据保管，不上传到公开问题单或代码仓库。

更新成功后会询问是否删除**本次**备份：默认“否，保留”，回车／取消也保留。建议先保留，等真实语音测试通过后再自行清理。选择“是”只删除本次经记录和验证的备份，不清空其他历史备份；清理失败不影响已成功安装的程序。

完整备份和暂存需要额外磁盘空间。安装器会预估目标磁盘空间，不足时停止；单文件 Setup 自身解包也需要系统临时目录有可用空间。备份失败不会继续替换程序。外部数据不能与程序受管理目录、备份目录或事务目录相互嵌套造成递归复制。

## 失败和中断

- 普通替换或自检失败时，恢复旧程序文件，保留备份。用户数据没有被更新器改写，无需自动还原。
- 关闭 Setup 或系统中断后，重新运行 Setup；它先处理未完成事务，再允许新操作。
- 发现事务损坏、备份缺失或外部修改时会停止。保留 `.comfybridge-install` 和对应备份，不要通过删除状态文件“解除保护”。
- 多文件更新不是一个原子的磁盘操作；可恢复不等于断电时仍能立即启动，也不能防止磁盘硬件损坏。
- 新版运行过之后，**不要直接用旧备份覆盖任务账本**。旧账本可能缺失后来提交的远端任务，造成重复生成风险。确需恢复数据时，先停止所有相关实例、核对任务和远端状态，再明确决定恢复范围。

## 边界

当前面向本地单用户使用。旧版无法识别新增安装锁，更新期间不要从其他会话、旧快捷方式或其他安装副本重新启动程序；使用同一外部数据目录的所有实例都必须停止。访问权限或占用无法确认时，安装器拒绝继续。

不提供联网自动更新、强制结束进程、自动业务重启、降级、卸载器或系统级安装。未签名的 EXE 可能触发 SmartScreen；应核对可信发布来源和文件 SHA-256，不应关闭系统安全防护。哈希不是代码签名。

业务设置和缓存规则保持原样，见 [使用说明](<../README.md>)、[定时缓存](<CACHE_030.md>)。
