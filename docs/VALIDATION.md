## 已通过：本机进程与管理

自动化测试在独立临时目录、隔离端口和本机不可连接的假 ComfyUI 地址上验证，没有发送真实生成请求：

- 后台独立启动，Q 关闭 Monitor 后后台仍存活；重复启动被拒绝。
- 管理接口绑定回环地址，业务 Key 不能替代管理凭证，校验 Origin、Host、实例标识与协议版本。
- 实际 Windows DACL 检查仅授权当前用户与 SYSTEM；跨进程互斥检查通过。
- 独立重启控制进程排空并重启；候选端口被本测试持有时，尝试一次最后成功快照回退，保留待生效配置。
- 强制停止仅停止本测试 Bridge，账本保留，锁释放；测试结束无相关遗留进程。
- 未创建真实登录自启动快捷方式，未修改防火墙。

## 目录包的自动验收门槛

构建脚本必须在生成 ZIP **之前**运行打包烟测；失败时不生成最终 ZIP。每个成功 ZIP 内的 `docs/PACKAGED-SMOKE.json` 是对应构建的实际结果，不能用另一个构建的报告替代。

打包烟测包含：

- EXE 帮助及启动；PATH 只保留 Windows System32，移除 PYTHONPATH 和 VIRTUAL_ENV。
- 独立临时中文／空格路径数据目录。
- 通过 TCP 访问打包后的 EXE，后端连接本地模拟 ComfyUI；不消耗真实 GPU。
- OpenAI SDK 读取模型列表及 WAV／MP3，实际调用包内 FFmpeg 和全部共享 DLL。
- 关闭 Monitor 后后台继续服务，完成后停止自有后台。

这是**本机隔离 PATH 的打包测试，不等于干净 Windows 虚拟机验收**。

其他已知边界：

- Windows 互斥使用 Local 命名空间，限定单一登录会话；不要跨多个登录会话共享同一数据目录。
- 源码、目录包未代码签名；公开再分发前需补充第三方依赖的完整许可／源码审核，见 [第三方说明](<THIRD_PARTY.md>)。
- ComfyUI history 是易失状态，无法保证端到端 exactly-once；未知任务需要核对或明确人工放弃，不自动重放。
- 不提供公网部署、多用户隔离、通用不可信工作流沙箱、历史音频库或动态情绪控制。
