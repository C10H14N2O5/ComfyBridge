# ComfyBridge 0.2.0 双语菜单版

## 使用方式

整个 Windows x86_64 目录解压后双击 EXE。首次选择简体中文或 English，以后不再询问，可从首页 A 修改。首次配置保存后自动启动／连接后台，再显示纵向编号菜单；日常配置、模型、音色、状态、启停和自启动都可在菜单完成。

- [完整使用说明](<../README.md>)
- [0.2.0 自动化与打包验收](<UI_020_VALIDATION.md>)
- [0.1.0 历史交付](<RELEASE_010.md>)，原本机 ZIP 不覆盖、不删除。

**升级前先在旧版窗口停止旧后台；只关闭窗口不等于停止。** 将新版解压到另一目录，完整迁移数据或指定原数据目录。旧配置有效时仅补选语言，不重新设置业务 Key。若有旧 Startup 登记，按使用说明从对应数据目录更新／禁用。

## 验证与分发

最终源码回归：**673 passed、6 skipped**。跳过项均因缺少 Windows 文件 symlink 权限；junction 测试通过。

构建必须先通过真实 EXE 的隔离 PATH、双语首页、嵌套菜单、语言切换不重启、取消重启、后台独立存活、模型列表、包内 FFmpeg WAV／MP3 和正常停机检查，才生成 ZIP。每个成功目录包包含对应 `docs/PACKAGED-SMOKE.json`、`BUILD-INFO.json` 和逐文件 `SHA256SUMS.txt`；请按该构建的报告核对，不把历史结果视为当前文件的结果。

Git 仓库只推送源码、测试、示例和文档，**不包含 ZIP、音频、运行数据、正式 Key、模型权重和参考音频**。完整 ZIP 从本次交付附件获取；自行构建参照 [README](<../README.md>)。压缩包的具体文件名、大小和 SHA-256 在交付回复给出，以避免包内文档对自身哈希产生循环依赖。

本次没有追加真实 GPU 生成，也没有启用用户实际登录自启动或修改防火墙。实际 AstrBot 安装、第二个音色、干净 Windows VM、真实登录自启动及人工窗口视觉检查仍需用户验证。程序未签名，公开再分发前仍需完整第三方许可审查。
