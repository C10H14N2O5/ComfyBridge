# ComfyBridge 0.3.0 定时缓存版

## 使用方式

整个 Windows x86_64 目录解压后双击 EXE。首次选择简体中文或 English，以后可从首页 A 修改。首次配置保存后自动启动／连接后台，再显示纵向编号菜单。

新增入口：**主菜单 6 → 修改模型或缓存策略 → 4 定时丢弃**。设置秒数和 `/free`／短生成方式，确认风险后保存，明确重启生效。示例 IndexTTS 使用短生成方式；正常业务保留缓存，到期使用最后调用的音色预设、短文本和 false 缓存参数进行一次清理。

**升级前先在旧版窗口停止旧后台；只关闭窗口不等于停止。** 新版解压到另一目录，完整迁移数据或指定原数据目录，不删除任务账本。旧配置与语言偏好继续可用。若有旧 Startup 登记，按使用说明从对应数据目录更新／禁用。

旧版程序不认识新缓存策略；回退前先在新版切回原三种策略并保存，再停止新版后台、使用旧版启动。备份包含业务 Key，应按敏感数据保管。

## 验证与分发

源码最终数字和真实显存采样见 [验收记录](<CACHE_030_VALIDATION.md>)。默认构建和测试只访问模拟 ComfyUI；真实实验脚本要求独立授权参数，保留意图与任务账本，不重放已存在案例。

构建必须通过真实 EXE 的隔离 PATH、双语菜单、语言切换不重启、取消重启、后台独立存活、包内 FFmpeg WAV／MP3、两轮定时短生成和一次原生空响应 `/free` 检查，才生成 ZIP。成功目录包附对应 `docs/PACKAGED-SMOKE.json`、`BUILD-INFO.json` 和逐文件 `SHA256SUMS.txt`。

完整 ZIP 从本次交付附件获取；自行构建参照 [README](<../README.md>)。具体文件名、大小和 SHA-256 在交付回复给出，避免包内文档对自身哈希产生循环依赖。包内不包含正式 Key、运行数据、模型权重或参考音频；本轮未自动推送 Git。

`/free` 受理及工作流完成不等同于所有插件显存都已释放。未修改用户实际登录自启动或防火墙；干净 Windows VM、真实登录行为、所有 AstrBot 安装和任意自定义节点不在已验收范围。程序未签名，公开再分发前仍需完整第三方许可审查。
