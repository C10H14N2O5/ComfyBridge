# ComfyBridge 0.4.0 离线安装版

## 使用方式

下载一个版本化 Setup EXE（可改名为 Setup.exe），放入专用可写文件夹，双击选择 `1. 安装 / Install`。安装完成后自行打开生成的 ComfyBridge.exe，首次配置与双语主菜单保持不变。

升级时先在旧版停止后台并退出所有窗口，将新版 Setup 放回原目录，选择 `2. 更新 / Update`。确认数据备份路径后，安装器完成备份、校验及替换；成功后询问是否删除本次备份，默认保留。相同版本可以修复，较旧版本禁止覆盖。

- [安装器验收范围](<SETUP_040_VALIDATION.md>)
- [完整使用说明](<../README.md>)
- [定时缓存说明](<CACHE_030.md>)
- 历史记录：[缓存验收](<CACHE_030_VALIDATION.md>)、[双语界面验收](<UI_020_VALIDATION.md>)、[首版验收](<VALIDATION.md>)

**关闭窗口不等于停止后台。** Setup 不强杀进程，不自动启动业务，不修改自启动或防火墙。外部数据路径的选择仅用于备份，不改变原有启动参数。

## 分发与验证

构建先验证完整 onedir 运行目录，包括双语菜单、后台独立运行、WAV／MP3 和定时缓存，再封装单文件离线安装器。安装器烟测使用隔离测试目录和模拟服务，验收完成才发布最终 EXE。真实语音业务应由用户在更新后自行启动检查；本地安装自检不等于真实业务验证。

文件名、大小、SHA-256 和本次实测结果在交付时提供，避免包内文件对自身哈希循环依赖。源码构建入口见 [README](<../README.md>)。保留历史发布产物，不覆盖删除旧包。

安装包不包含生产 Key、用户运行数据、模型权重或参考音频。备份含敏感数据，仅留在用户本机。程序未签名；SHA-256 不能替代可信来源和代码签名。干净 Windows VM、任意多用户场景、所有 AstrBot 安装和所有 ComfyUI 插件不作为默认保证。本轮不自动推送 Git。
