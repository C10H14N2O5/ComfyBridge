# v0.4.0 安装器验收范围

## 发布门禁

最终 Setup 的构建流程先验证完整程序目录，再用真实 Setup EXE 在隔离目录执行安装／更新测试。只有全部必需步骤成功才复制生成最终版本化安装器；失败的调试构建不作为交付。

- 完整源码 pytest 回归：原 API、音频、缓存、界面和进程生命周期测试，以及新增安装器测试。
- 严格载荷测试：目录遍历、保留路径、大小写冲突、重复成员、链接、缺失／额外文件、错误哈希和版本。
- 事务测试：首装、旧目录更新、同版修复、降级拒绝、未知文件保留、冲突、空间不足、ACL、备份及自检失败。
- 故障测试：撤下／发布／receipt 提交前后中断，恢复过程再次中断，相同内容修复，首次安装嵌套目录清理及重新安装。独立子进程使用 `os._exit`，不只依赖可捕获的 Python 异常。
- Windows 检查：真实 NTFS／ACL、跨进程共享／独占文件租约、只读 Restart Manager、窗口占用、重解析点及硬链接；非交互输出使用 UTF-8。
- 真实 EXE：中文及空格路径、从其他工作目录运行 Setup、新安装、同版修复、保留／删除本次备份、未知文件与外部数据保持不变、现版和旧版配置窗口占用拒绝更新。
- 安装后业务：模拟 ComfyUI 下的双语菜单、后台独立存活、WAV／MP3、两轮工作流定时清理和一次原生 `/free`。关闭后的实例租约也必须释放才清理测试目录。

测试安装器进程树在专用 Windows Job 内启动，超时只终止这个测试创建的进程树；此逻辑仅在开发烟测脚本中，产品 Setup 没有终止用户进程的功能。

## 证据与边界

精确通过／跳过数字、最终 EXE 文件名、大小及 SHA-256 在交付结果中给出。开发侧保存 `artifacts/installer-smoke.json`、`artifacts/setup-build.json` 和 `artifacts/release-040-verification.json`，最终核对安装器哈希、运行目录逐文件校验和及源文件一致性。运行目录附 `docs/PACKAGED-SMOKE.json`。

旧版兼容使用现有原始发布包和历史格式样例；内部测试记录区分原包和样例，不把模拟目录测试当作原包实测。未修改实际业务数据、自启动或防火墙，没有提交真实 GPU 任务。干净 Windows VM、第二登录会话下的端到端更新和物理断电不在本次本机测试保证内；跨会话锁是 OS 文件共享语义，不等于已做多用户安装验收。

多文件更新仅保证可检测／可恢复的事务设计，不承诺断电原子性或抵御磁盘硬件损坏。程序文件校验和本地自检通过不等于真实 TTS 业务或所有插件已验证。
