# 0.2.0 双语与统一菜单验收

本次只改本机使用交互，保留业务 API、任务恢复、配置 schema 和音频处理协议；没有新增真实 GPU 生成，也没有更改用户的实际 Startup 或防火墙。

## 冻结源码回归

```powershell
$env:COMFYBRIDGE_DESKTOP_SMOKE='1'
.venv\Scripts\python.exe -m pytest -q
```

**673 passed、6 skipped、1 warning，40.61 秒。**

6 项跳过均为本机无权创建文件符号链接（WinError 1314）；实际目录 junction、私有目录 DACL 和跨进程互斥测试通过。警告为 Starlette TestClient 的 httpx 弃用提示。

覆盖：

- 中英文文案键、格式占位符和外部文本的终端安全处理。
- 首次语言选择、持久化、切换、取消、无效／不可写偏好、独立数据目录、原子保存及单独写锁。
- 中断首次语言选择不会继续启动后台；后台／脚本命令不弹语言菜单，status JSON 不被提示文字污染。
- 首次配置：每字段修正、完整音色导入、模型／音色可延后、摘要、明确保存、放弃和保留草稿继续编辑。
- 原配置兼容；语言变化不改业务摘要，不让服务出现待重启状态。
- 主菜单只在进入时自动启动一次；刷新、从 Monitor 返回或手动停止之后不会再次自动启动。
- 启动失败保留菜单；控制器独立运行时仍能看到重启进度／失败；无法确认身份不冒充已停止。
- 统一输入读取，避免管道 TextIO 预读使 Monitor 操作错位成首页操作；覆盖选择／确认／秘密输入／UTF-8 路径／返回边界。
- Monitor 3/R 重启、停止、强停有明确确认，空回车默认取消；Q／0／EOF／关闭观察窗口不停止服务。
- 配置诊断不回显未知 JSON 字段名或字段值；仍显示已知字段位置和安全错误码。
- 旧 CLI 参数与源代码时期 Windows 后台、回退和转码回归全部保留。

## 打包验收门槛

构建脚本在所有检查通过后才生成 ZIP；实际对应结果保存在包内 `docs/PACKAGED-SMOKE.json`。

除基础启动／转码／停机外，新增：

- zh-CN／en-US 两种已保存偏好对应的真实 EXE 主菜单。
- 高级摘要 → 返回 → Monitor → 返回主菜单。
- Monitor → 配置编辑 → 取消 → Monitor → 首页，确认同一输入流没有错位。
- 空回车取消重启，不创建重启控制记录，不更换后台实例。
- 从主菜单切换语言后立即切换并持久化，后台实例及业务摘要不变。
- UTF-8 重定向输出可解码，不含业务 Key；重复启动不再次询问语言。
- 保留中文／空格临时路径、仅 System32 的 PATH、包内 FFmpeg WAV／MP3 和正常停止验证。

打包验收使用本机模拟 ComfyUI，**没有访问真实模型生成接口**。这是本机隔离 PATH 验证，不是干净虚拟机或真实登录自启动验证。

## 仍需人工验证／保留边界

- 实际双击窗口的中文字体、窗口大小、鼠标关闭体验；自动化验证了文本与进程行为，不声称做过人工视觉验收。
- 真实用户登录自启动，干净 Windows x86_64 系统，实际 AstrBot 安装联调及第二个真实音色。
- 同一数据目录仍只支持一个 Windows 登录会话中的实例互斥；无跨会话服务保证。
- 无代码签名；公开再分发前需要完整第三方依赖许可与源码审核。
- 升级必须先通过旧版窗口停止旧后台，迁移配置后再启动新版；不跨版本冒充管理身份。
