## 必须覆盖的行为

- 旧配置及原三种策略兼容；新配置严格类型/范围、双语菜单、取消不保存、保存不执行远端操作。
- 全局业务活动重置、全部请求结束后开始完整间隔；长生成、交付、断连、未解决远端任务期间不卸载。
- 远端空队列检查、准备期间新请求竞态、卸载互斥门、多在途配置下等待队列上限、请求原始总超时。
- 原生 `/free` 200 空体、失败/结果不明不盲重试、实例级合并及不永久阻塞业务。
- 最后预设、缓存 true/false 覆盖、持久种子、不变模板、卸载不下载或转码、不自触发。
- SQLite 旧账本迁移、提交意图原子性、终态和缓存周期原子性、崩溃恢复、失配配置、排空和强停。
- SDK→ASGI→真实音频处理→协议模拟器的两种卸载端到端测试。

## 真实 ComfyUI 验证

2026-10-24，经用户明确授权，使用 LAN ComfyUI 与 NVIDIA RTX A3000 Laptop GPU、现有 Example 参考音频。测试数据目录与用户配置分离；不修改 ComfyUI 安装或画布。开始及结束队列均为空；调度器在每次卸载前另行检查队列。

完整脱敏原始记录见 [真实测试数据](<LIVE_CACHE_030.json>)。一共 **6 次生成（4 次业务保持缓存、2 次内部短生成卸载）及 1 次 `/free`**，无重放、无队列清空或全局中断。

| 检查 | 观测 |
|---|---|
| `/free` | 200 受理；自定义 IndexTTS 全局缓存仍在，Torch 报告值维持 5,603,590,144 字节 |
| 重启恢复待清理周期 | 已完成业务任务未重发，恢复后重新等待完整 10 秒，再发送一次 `/free` |
| 新业务重置倒计时 | 剩余 7.575 秒 → 第二次生成结束后 9.795 秒 |
| 第一轮短生成卸载 | Torch 报告值 5,603,590,144 → 167,772,160 字节（5.21875 → 0.15625 GiB） |
| 卸载后再次生成 | WAV 成功，25.086 秒；Torch 报告值重新升到 5,570,035,712 字节 |
| 第二轮短生成卸载 | 5,570,035,712 → 167,772,160 字节（5.1875 → 0.15625 GiB），再次回到基线 |
| 清理种子 | 两轮分别为 1、2；正常业务种子保持模板原值 |
| 工作流阶段 WAV | 三次收到 168,378／126,582／160,576 字节音频，分别用时 9.468／7.212／25.086 秒 |

这里的 Torch 数值是 ComfyUI `system_stats` 报告的显存指标，不等同于全机显存使用量，也不保证其他插件有相同行为。两轮清理后设备可用显存都回到 11,686,080,192 字节，和初始基线一致。

### 测试脚本路径修正（未重发已完成任务）

首次业务生成远端成功，但脚本使用多层输出目录，Windows ComfyUI 在音频描述中返回反斜杠子目录，被既有严格路径校验以 `invalid_audio_descriptor` 拒绝下载。未修改产品安全校验；将后续测试输出改为单层目录，并添加纯本地回归用例。

首次意图和失败记录保留；继续测试前再次核实该 prompt 已成功，从持久账本恢复其待清理周期，只执行尚未执行的 `/free`。之后使用新的隔离目录完成工作流测试，没有重复提交首次生成。后续真实实验脚本同样使用单层输出目录，并拒绝覆写已有案例。

## 打包验收

默认构建在独立中文/空格目录、隔离 PATH 中运行真实 EXE，通过后才生成 ZIP。必须覆盖双语首页与嵌套导航、语言切换不重启、取消重启、观察窗口退出后后台存活、WAV/MP3、两轮定时短生成（不同种子、不下载清理音频、不自触发）、明确停机切换到 `/free` 并接受其空 200 响应、最终正常停机。

具体结果随包 [打包烟测报告](<PACKAGED-SMOKE.json>) 提供；该报告由构建生成，源码仓库不伪造同名结果。ZIP 的大小和 SHA-256 在交付回复列出，包内逐文件校验和独立验证。

## 保留边界

- `/free` 受理不证明显存已释放，且不能锁住其他 ComfyUI 客户端。本次真实验证使用自定义 IndexTTS 缓存，未额外加载 ComfyUI 原生管理的其他模型来证明其卸载效果。
- Windows ComfyUI 返回含反斜杠的嵌套输出子目录仍会被既有安全校验拒绝；本次示例验收使用单层输出目录，不宣称解决了该既有兼容边界。
- 用户 A/B 实测只证明所测同模型工作流副本共享可卸载缓存，不推广至不同权重或插件。
- 短生成可能在远端留下音频文件；本项目不删除远端输出。
- 不保证干净 Windows VM、实际登录自启动、多登录会话、所有 AstrBot 版本或任意自定义节点兼容。
- 未修改 ComfyUI 安装或画布、用户实际 Startup 或防火墙；本轮不自动推送 Git。
